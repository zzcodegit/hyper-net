# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Hypernet, please DO NOT open a public GitHub issue.

Instead, report it privately by emailing:

security@hypernet.dev

(If this email does not exist yet, replace it with your real contact.)

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

We aim to respond within 72 hours.

---

## Scope

This policy applies to:

- Core networking layer
- Proxy protocols
- DHT / DNS implementation
- Relay & VPN components
- Subscription logic (future)

---

## Responsible Disclosure

We ask researchers to:

- Give us reasonable time to fix the issue
- Avoid public disclosure before patch
- Avoid exploiting vulnerabilities beyond proof of concept

---

## Security Philosophy

Hypernet is a distributed systems project.

Security principles:

- Minimize trust assumptions
- Avoid hidden backdoors
- Keep networking and economic layers separated
- Prefer explicit boundaries over implicit behavior
