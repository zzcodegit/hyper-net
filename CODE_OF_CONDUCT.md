# Code of Conduct

## Our Commitment

We are committed to building a professional, respectful, and technically focused community.

This project values:

- Constructive discussion
- Technical clarity
- Respectful disagreement
- Evidence-based arguments

---

## Expected Behavior

- Be respectful.
- Focus on technical reasoning.
- Provide context and reproducible examples.
- Critique ideas, not people.

---

## Unacceptable Behavior

- Personal attacks
- Harassment
- Hate speech
- Spam or low-effort trolling
- Aggressive behavior

---

## Enforcement

Maintainers may:

- Edit or remove inappropriate content
- Lock discussions
- Ban repeat offenders

We prioritize long-term architectural integrity over short-term popularity.

---

## Philosophy

Hypernet is an infrastructure project.

We build thoughtfully.
We value correctness.
We value clean architecture.
We value collaboration.
